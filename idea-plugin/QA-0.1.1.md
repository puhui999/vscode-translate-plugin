## 自动化

在 `idea-plugin` 下执行：

```sh
JAVA_HOME='/opt/homebrew/opt/openjdk@25/libexec/openjdk.jdk/Contents/Home' \
  ./gradlew -PlocalIdePath='/Users/parentalzen/Applications/IntelliJ IDEA.app/Contents' \
  test buildPlugin --console=plain
```

结果：**BUILD SUCCESSFUL；115 项测试，0 失败、0 错误、0 跳过**。JUnit XML 位于 `build/test-results/test/`，HTML 报告位于 `build/reports/tests/test/`。

本次新增 9 项原生编辑器替换测试、9 项编辑动作保护测试和 1 项完整布局测试，覆盖：

- 独立注释使用完整多行译文，边界光标不被隐式移动，清理与销毁恢复原文。
- 单行文档注释、行内注释、与代码混排的多行块注释；保留精确范围之外的代码。
- 内部光标、选择范围、显式恢复译文、修改后 ID 变化及过期源码检查。
- 原生普通文档折叠、外层代码折叠与内置文档渲染有效设置的恢复。
- Delete、Backspace 的第一次操作只揭开原文，第二次交给真实原生处理器删除一个字符。
- Cut、DeleteLine、多光标、跨折叠选择和行内折叠的首操作保护；没有译文时正常委托；允许空 DataContext。

已有解析、格式还原、HTTP Mock、批次、缓存、取消和状态测试一并通过。真实鼠标悬停、所有快捷键与第三方插件组合不属于这些自动化测试的覆盖范围。

## 验收边界

悬停原文已实现并经过源码检查，本轮没有独立的鼠标悬停截图验收。分栏、字体调整、HTML 实际 UI、普通复制、撤销及只读快照未逐项重复人工验收；相关既有功能或自动化覆盖不等同于本轮人工验证。

原位显示基于编辑器折叠，逻辑行号、普通复制与编辑仍依据原始 Document。行尾或代码中的多行译文合并为单行；完整译文可通过专用复制动作或只读快照获取。查看原文后保留供编辑，使用显式动作切回译文。

退出原位显示恢复接管前当前编辑器的有效文档渲染布尔状态，不承诺恢复继承全局设置等内部模式。其他 JetBrains IDE、旧版 IDEA、远程开发、第三方折叠/文档插件和真实模型差异未验收。Markdown 全文、JS/TS/Vue、HTML 内嵌 JavaScript/CSS 注释不在本版范围。
