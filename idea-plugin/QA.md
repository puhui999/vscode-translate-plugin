# 0.1.0 验证记录

本地验证环境为 macOS、IntelliJ IDEA 2026.2.0.1（262.8665.337）。使用单独的 IDE 配置、系统目录和生成的 Java/XML 项目，接口连接本地 HTTP Mock，没有调用真实模型。

## 真实 IDE 检查

- 离线示例显示 5 组译文，包含单行 Javadoc、带 `@param` / `@return` 的文档注释、普通与行尾注释、长译文。
- 点击文档译文的展开操作后，完整注释边界可见，源码光标仍停在原来的 `1:1`。
- 只读快照中的译文保留注释符号、缩进、参数名与文档标签；源码编辑器仍显示原文。
- 在原生设置中填写本地兼容服务与模型后，打开 Java 文件自动翻译。4 个注释块合并为一次 HTTP 请求，状态栏显示“4 条 · 缓存 0”。
- 关闭 Java 标签并重新打开，状态栏显示“4 条 · 缓存 4”，HTTP 请求总数仍为 1。
- XML 文件的注释自动翻译，显示 `<!-- 中文译文 -->`，增加一次只包含该注释的请求。
- 在生成的 Java 测试文件中插入并撤销空行后，已有注释使用缓存重新显示，未新增翻译请求。

## 自动化验证

本地执行 `./gradlew test buildPlugin`，96 项测试全部通过，ZIP 打包成功。测试覆盖解析与格式恢复、SQLite 读写和淘汰、批次协议与错误响应、本地 HTTP 取消/超时、原生 Editor Inlay、换行布局、设置保存顺序，以及部分翻译后恢复自动任务的完成状态。测试不需要真实 API Key。

CI 在 Linux 上使用官方同版本 IDEA 和 JDK 25 执行测试及 ZIP 打包。每次运行的准确结果以 Actions 和生成的 JUnit 报告为准。

## 当前验证边界

原生 UI 手工检查集中在 Java/XML，Kotlin 与 HTML 的识别由平台解析测试覆盖。尚未验证旧版 IDEA、其他 JetBrains IDE、远程开发和真实厂商模型的所有协议差异。

只读视图是创建时的快照，长文件性能和更多语言支持继续迭代。IDE 自身的 Javadoc 渲染模式、第三方显示插件等组合尚需更多真实使用反馈。
